# Enterprise Knowledge Assistant

A production-ready AI-powered document intelligence system built with FastAPI, PostgreSQL, SQLAlchemy, LangChain, FAISS, OCR, and LLMs.

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
- LangChain
- FAISS
- HuggingFace
- Docker

Project currently under development.
